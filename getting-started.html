Guides

Getting Started

Contents
  1. Requirements
  2. First steps
  3. Creative tab
  4. If something goes wrong

Requirements

  • Minecraft Java Edition 26.3 and Java 25
  • Fabric Loader 0.20.1 or higher
  • Fabric API (26.3)
  • GeckoLib 5.5.7 for Fabric 26.3 (geckolib-fabric-26_3-5_5_7.jar)

Put the three .jar files (Fabric API, GeckoLib and LivingWild) in the mods folder.

First steps

  1. Create a new world (structures only generate in new chunks).
  2. Find a Medieval House and talk to its NPCs: they will show you the world.
  3. Go down to the deep caves (Y −30 to −20) for Petronite Ore.
  4. Follow the Progression Guide.

Creative tab

All the content is in the LivingWild tab: items, blocks and spawn eggs (NPCs, bosses, hostile creatures). Dragons are obtained from their egg.

If something goes wrong

Check the FAQ and Compatibility.
