Guides

Compatibility

ModSupport
Fabric API and GeckoLib 5.5.7Required.
EMF / Fresh AnimationsThe 3D armor and the wings follow the player's animated pose (no hard dependency).
Punchy MovesRecognizes the Dawnblade (sword tag), the Stormaxe (axes) and the Petronite Pickaxe (pickaxes); the armor takes the animated pose.
Do a Barrel RollIf it is installed, LivingWild's camera tilt turns itself off to avoid clashing; the dragon and rider still tilt. See Riding a Dragon.
ShadersThe glow of petronite and the staff does not depend on special effects, so it is compatible.

If an animation mod does not get along with the 3D model, report the game log.
