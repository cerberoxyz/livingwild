Guides

Configuration

Contents
  1. Options
  2. Trade format
  3. NPC IDs
  4. Generation settings (datapack)

When the game starts, the mod creates the config/livingwild.json configuration by itself the first time. Edit it and restart the game to apply the changes.

Options

KeyDefault valueWhat it does
maxNpcsPerChunk8Maximum number of NPCs of the same type per chunk. Those that already exist in the world are not deleted.
npcs.<id>.enabledtrueSet false to disable an NPC type.
npcs.<id>.trades(see each NPC)The NPC's list of trades.
hireCost32 emeraldsCost of hiring a companion (same structure as a trade).

Trade format

{
  "input": "minecraft:emerald",
  "inputCount": 20,
  "output": "minecraft:golden_apple",
  "outputCount": 1
}

The IDs are the normal Minecraft ones, e.g. minecraft:diamond. You can change prices or add trades.

NPC IDs

caballero, mago, hada, mercader, herrero, arquero, campesino, alquimista, bardo, guardia, jugador, monje.

Migration: The Fairy no longer trades: if the file comes from an old version, the mod removes her trades except the Fairy Heart one, and the Heart is now crafted with a recipe.

Generation settings (datapack)

  • Ore height and amount: data/livingwild/worldgen/placed_feature/mena_de_petronita.json.
  • Structure frequency: worldgen/structure_set/*.json (spacing and separation).
